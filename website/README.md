# Valexii Governed Intelligence

Build a new PRIVATE VALEXII.AI public website prototype for valexii.com. This is a separate public-site project, not the existing VALEXII Control Nexus and not the old CoreGuard Companion.

Canonical public hierarchy:
VALEXII.AI = parent governed-intelligence organization/platform.
MEDAURUS = mobile cybersecurity product.
XAELI = human-facing governed-intelligence experience.
DISPATER.AI = industrial-intelligence application direction.

Public story: Evidence → Qualification → Reality → Authority → Effect, described in plain English without revealing proprietary mechanics.

Design: near-black/deep navy, luminous cyan/teal, crisp white, restrained metallic gold, premium Roman/imperial display influence with modern readable body typography. More technology, less fantasy. No gods, warriors, temples, generic AI brains, crypto aesthetics, or cyberpunk wallpaper.

Site structure: Home hero; Why Governed Intelligence; interactive Evidence→Qualification→Reality→Authority→Effect section; MEDAURUS; Shield/Sense/Analyze product modes; XAELI; DISPATER.AI; Research/Collaboration; Founder/Origin; Contact; Privacy; Terms. Keep normal-user surfaces simple and premium.

MEDAURUS public navigation shown in concept visuals should follow Home / Modes / XAELI, with Activity and Settings secondary. Public modes are Shield, Sense, Analyze. Watch is folded into Sense; Guide is handled through XAELI. Any concept UI must be visibly labeled as concept, not production screenshots.

XAELI should be represented as a calm governed interface, evidence explanation, uncertainty and human control—not a fantasy humanoid.

Claims must be conservative and public-safe: use “is being developed,” “designed to,” “explores,” “aims to,” or “seeks validation” where appropriate. Do not invent customers, partners, certifications, deployments, performance metrics, university endorsement, funding, or security guarantees. Do not expose SATOR, ROTAS, TENET, LEVEL, repository details, SHAs, Firebase internals, test infrastructure, source code, or patent-sensitive implementation.

Build responsive mobile/tablet/desktop layouts, WCAG-oriented accessibility, reduced motion support, optimized image placeholders, metadata structure, and a restrained contact form design. Do not deploy or connect a domain. Keep this as a private build/prototype for review.
