# Security Policy

## Reporting

Please do not open public issues for vulnerabilities that could expose credentials, private data, or exploitable implementation details. Use GitHub's private vulnerability reporting when enabled.

## Public-repository boundary

Never commit API keys, tokens, production telemetry, personal data, proprietary BCXMET internals, private prompts/orchestration, or patent-sensitive mechanisms.

AUREX output is advisory evidence. Integrators must not treat a successful AUREX result as sufficient authorization for a security-sensitive effect.

## Supported versions

AUREX is pre-alpha. No release is currently designated production-ready.
