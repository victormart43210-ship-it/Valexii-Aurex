# Release readiness checklist

Before requesting owner approval to progress toward production deployment, ensure the following are satisfied:

- [ ] Baseline verification commands executed on staging with the same commit
- [ ] End-to-end staging exercise completed and recorded in end-to-end-results.md
- [ ] Jules independent verification performed and findings addressed
- [ ] No privileged credentials exposed in frontend bundles
- [ ] Rate limits and quotas defined and enforced
- [ ] Rollback and monitoring plan documented
