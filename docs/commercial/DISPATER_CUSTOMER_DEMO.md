# DISPATER.AI — Customer Demonstration Guide

**Target Audience:** Industrial Operations Managers, Fleet Dispatchers, CFOs
**Ecosystem:** VALEXII.AI / AUREX-OX

---

## Demonstration Journey

1. **Revenue Assurance Overview:** View organization-level potential exposure ($17,000+ USD) categorized into non-overlapping financial buckets.
2. **Findings Explorer:** Search and filter exceptions by rule category (`UNMATCHED_PO`, `UNBILLED_FIELD_TICKET`, `RATE_DISCREPANCY`, `DUPLICATE_INVOICE`).
3. **Evidence Inspector:** Inspect original SHA-256 digests and supporting field ticket/invoice references.
4. **XAELI Explanation Panel:** View the canonical 5-step explanation (`NOW` -> `CHANGED` -> `NEXT` -> `WHY` -> `PROOF`).
5. **Human Review Queue:** Approve billing corrections or mark findings as disputed/dismissed.
6. **Value Calculator Simulator:** Explore conservative, baseline, and optimistic ROI scenarios with customer-specific assumptions.
