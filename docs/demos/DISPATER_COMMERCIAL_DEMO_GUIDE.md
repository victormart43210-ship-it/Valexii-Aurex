# DISPATER.AI Commercial Demonstration Guide for Towing Companies

## Overview
This guide describes the 5-minute commercial demonstration procedure for towing company executives and fleet directors using synthetic records.

## Demo Flow

### 1. Before DISPATER (Operational Friction)
- Scattered paper records, expired brake inspections, conflicting maintenance logs, and unverified service tickets.
- Manual audit preparation takes hours with high compliance risk.

### 2. With DISPATER (Connected Synthetic Intelligence)
- Open `/dispater` in any browser.
- Select target synthetic towing records and click **Initiate Authenticated Audit**.
- View real-time state execution and XAELI 5-step findings (NOW, CHANGED, NEXT, WHY, PROOF).
- Identify exceptions immediately:
  - Expired Heavy Wrecker Brake Inspection (`demo-vehicle-01`)
  - Conflicting Winch Pressure Test Log Digests (`demo-maint-01` vs `demo-maint-02`)
  - Unverified Field Ticket Source Digest (`demo-ticket-01`)

### 3. Operational Work Queue & Human Review
- Navigate to the **Operational Work Queue** to assign, review, request evidence, or resolve flagged issues.
- Log human review dispositions (ACKNOWLEDGED, DISPUTED, NEEDS EVIDENCE, RESOLVED).

### 4. Export Digital Audit Binder
- Click **Export Audit Binder (.json)** to generate a reviewable synthetic audit package complete with SHA-256 evidence integrity manifests.
