# DISPATER.AI Versioned Audit Data Contracts

**Platform:** DISPATER.AI
**Module:** Audit & Monitoring Data Contracts (`aurex/dispater_contracts.py`)
**Date:** October 2026
**Status:** SPECIFICATION & SCHEMA REFERENCE

---

## 1. Overview

DISPATER.AI enforces strict Pydantic v2 data models for all ingested operational records, monitoring observations, versioned audit rules, findings, corrective actions, audit readiness evaluations, and verification receipts.

These schemas establish deterministic data boundaries between raw industrial observations and verified evidence artifacts.

---

## 2. Core Schemas & Structures

### 2.1 `OperationalRecord`
Ingestion schema for field tickets, inspection sheets, equipment logs, and telemetry observations.

```json
{
  "record_id": "REC-FT-1001",
  "tenant_id": "TENANT-OILFIELD-01",
  "source": "OILFIELD_FIELD_TICKET",
  "timestamp": "2026-10-25T14:30:00Z",
  "payload": {
    "ticket_id": "FT-1001",
    "po_id": "PO-8821",
    "pump_hours": 12.5,
    "has_signature": true
  },
  "content_sha256": "4a5e2f...",
  "is_independently_verified": false
}
```

### 2.2 `MonitoringObservation`
Continuous monitoring observation emitted during anomaly or record ingestion scanning.

```json
{
  "observation_id": "OBS-20261025-001",
  "tenant_id": "TENANT-OILFIELD-01",
  "record_ids": ["REC-FT-1001"],
  "observed_at": "2026-10-25T14:31:00Z",
  "observation_type": "MISSING_INSPECTION",
  "severity": "HIGH",
  "details": {
    "equipment_id": "RIG-UNIT-104",
    "issue": "OSHA/DOT inspection certificate expired 3 days ago"
  },
  "evidence_sha256": "8f1a2c..."
}
```

### 2.3 `AuditRule`
Configurable operational, contractual, or compliance audit rule.

```json
{
  "rule_id": "RULE-OIL-INSP-01",
  "rule_version": "1.0.0",
  "domain": "SAFETY_COMPLIANCE",
  "title": "Mandatory Daily Pre-Job Safety Inspection",
  "description": "All pressure pumping equipment requires an active pre-job inspection log on file before operation.",
  "effective_date": "2026-01-01",
  "source_reference": "OSHA 1910.120 / DOT CFR 396",
  "severity": "CRITICAL",
  "is_active": true
}
```

### 2.4 `AuditFinding`
Discrepancy or non-compliance finding generated by rule evaluation.

```json
{
  "finding_id": "FND-20261025-88",
  "rule_id": "RULE-OIL-INSP-01",
  "tenant_id": "TENANT-OILFIELD-01",
  "severity": "CRITICAL",
  "title": "Pressure Unit Operating Without Active Inspection",
  "description": "Rig Unit 104 operated 12.5 hours without daily safety inspection record.",
  "source_record_ids": ["REC-FT-1001"],
  "evidence_sha256": "9b3e1c...",
  "status": "OPEN",
  "assigned_owner": "Safety Director",
  "audit_event_ref": "AUDIT-INSP-1001",
  "is_demo": true
}
```

### 2.5 `CorrectiveAction`
Remediation tracking and independent retest workflow contract.

```json
{
  "action_id": "ACT-20261025-01",
  "finding_id": "FND-20261025-88",
  "tenant_id": "TENANT-OILFIELD-01",
  "assigned_to": "Field Safety Supervisor",
  "due_date": "2026-10-27",
  "remediation_notes": "Unit pulled for shop inspection and safety log attached.",
  "remediation_evidence_sha256": "c7a21b...",
  "retest_status": "RETEST_PASSED",
  "closed_at": "2026-10-26T09:00:00Z",
  "closed_by_human": "Chief Auditor"
}
```

  "total_records_evaluated": 150,

  "readiness_status": "AUDIT_READY",
  "assessment_sha256": "e3b0c44198fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855",

}
```

  "tenant_id": "TENANT-OILFIELD-01",
  "issued_at": "2026-10-25T15:01:00Z",
  "scope_record_count": 150,
  "findings_summary": {"OPEN": 2, "CLOSED": 14},
  "root_evidence_sha256": "7d9b2...",
  "receipt_sha256": "1f8e3...",
  "authority_disclaimer": "AUREX-OX EVIDENCE RECEIPT ONLY. MODEL OUTPUT AUTHORITY = NONE. FINANCIAL AUTHORITY = NONE. INDUSTRIAL CONTROL AUTHORITY = NONE."
}
```
