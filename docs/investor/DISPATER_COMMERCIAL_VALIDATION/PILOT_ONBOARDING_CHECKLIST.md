# DISPATER.AI — Commercial Pilot Onboarding Checklist

**Target Customers:** Oilfield Service Operators, Heavy Towing & Recovery Fleets, Equipment Rental Fleets

---

## Phase 1: Intake & Setup (Days 1–3)
- [ ] Sign Pilot Agreement and Non-Disclosure Agreement.
- [ ] Provide sample synthetic or anonymized historical field ticket CSV/JSON exports (minimum 100 tickets).
- [ ] Provide approved customer master rate sheets (rate codes, approved hourly/flat rates).
- [ ] Provide purchase order register (PO numbers, authorized financial limits).

## Phase 2: Reconciliation Benchmark Run (Days 4–7)
- [ ] Execute DISPATER `RevenueLeakageEngine` on intake batch.
- [ ] Generate 5-step XAELI findings report (`NOW`, `CHANGED`, `NEXT`, `WHY`, `PROOF`).
- [ ] Present exception queue to customer operations manager.

## Phase 3: Operational Value Review (Days 8–14)
- [ ] Review detected exceptions with human operations manager.
- [ ] Validate true positive discrepancy rate (target: >= 95% precision).
- [ ] Measure estimated administrative hours saved in review queue.
- [ ] Execute ROI Value Calculator with customer-supplied assumptions.
