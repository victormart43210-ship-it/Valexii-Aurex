### Eight fields required for every capture

1. **Source and time:** exact canonical main SHA, separate PR head SHAs, website source SHA, UTC window, working-tree status, and ownership of changed files.
2. **Evidence class:** record separately CODE PRESENT, LOCAL TESTED, CI VERIFIED, MERGED, DEPLOYED, LIVE WEBSITE HANDSHAKE, INDEPENDENTLY VERIFIED. One class never implies another.
3. **Verification:** exact SHA + command + environment + test counts + actual output location, failing/negative/adversarial cases, reviewer independent of implementation. Unavailable result → NOT RUN / NOT VERIFIED.
4. **Production truth:** Railway live source/image SHA, branch, root directory, deployment and rollback; **staged** volume/env changes kept distinct from **live**.
5. **Frontend truth:** actual published Lovable SHA; mobile performance measured on matched devices/settings; owner session and server-only authentication proof for the five read-only API GETs. No bearer in browser.
6. **Original financial evidence:** private local custody, source parser revision, synthetic RED/GREEN tests, independently labeled real-data misses and false positives, human review. USB originals never uploaded.
7. **Business:** only observed cost, revenue, retention, error rates and saved time; PR counts, imagined adoption and aspirational 9.9 scores are not measured business impact.
8. **Next unblock:** dependency, task owner, exact acceptance test, rollback and **separate approval** needed for an external effect.
