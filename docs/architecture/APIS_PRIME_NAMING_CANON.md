## Engineering design — the safe and maintainable way

1. **Names are labels, not 14 running AI agents or microservices.** Build one AUREX orchestrator with bounded, independently testable research tool adapters. Qwen is an untrusted model adapter. Deterministic filters, cipher checks and Python static inspection should not consume model calls by default.
2. **Permanent stable IDs, versioned display names.** Use `AP01`–`AP14` in research UIs and offline analytics. Historical technical method names remain in source attribution, package metadata and test reports. Never rename `QWEN` binaries, OpusFilter / LRPlan packages, external APIs, database columns or other upstream libraries because a display label changed.
3. **Identity is not deployment state.** Runtime capabilities and live status require a **separate, exact-SHA, independently witnessed readiness manifest**; labels alone must never set `available=true`, `verified=true`, `safe=true`, or alter customer-visible truth.
4. **Research cannot self-certify.** Independent challengers test alternative explanations; a SHA-256 digest documents integrity, not semantic validity. Preserve `Evidence → Qualification → Reality → Authority → Effect` and `UNKNOWN ≠ SAFE`.
5. **Scientific claims stay scoped.** Symbolic/numerological correspondences are not manuscript translations; entropy is not proof of encryption; AST inspection does not execute code and is not a vulnerability verdict; Qwen narratives do not establish facts.
6. **No permission expansion.** Research tool output cannot authorize production deployment, financial transactions, BCXMET security verdicts, access to private data, or model training. Require explicit user consent for live document ingestion; retain $0 default external spend.
7. **UI presentation:** owner-only AUREX/OX panels use the 14 locked names, existing VALEXII navy/cyan/violet/gold design and motion/accessibility settings. Do not display country names, geographical status labels, flags, fabricated telemetry or unverified live model availability.
8. **Respect and commercial review:** Several labels derive from deities in living Indigenous and other religious traditions. Before consumer-facing branding, request culturally informed review and trademark/domain clearance. This is a **naming lock for internal engineering**, not clearance for trademark registration or a public marketing launch.
