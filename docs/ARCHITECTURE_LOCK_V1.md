# AUREX Research & Verification Architecture Lock v1

**Status:** ARCHITECTURE LOCKED; IMPLEMENTATION / BENCHMARK RESULTS REQUIRE INDEPENDENT VERIFICATION.

## Governing law
AUREX is a witness, never the authority. The system may never be its own sole witness. Missing, stale, incomplete, contaminated, self-graded, or failed evidence cannot become PASS.

## Canonical pipeline
Evidence -> Qualification -> Reality -> Authority -> Effect.
Reverse audit: Result -> Authority -> Truth -> Admissibility -> Source.

## Universal experiment lifecycle
Hypothesis -> frozen baseline -> preregistered protocol -> isolated execution -> evidence capture -> independent challenge -> adversarial test -> remediation -> blind retest -> replication -> result.

Remediation never erases the original failure. Historical truth and current authority remain separate.

## Research tracks
1. Benchmark Lab: authorized HLE-style exams, synthetic exams, regression suites, calibration and adversarial reasoning.
2. Decipherment Lab: Voynich, Linear A, Rongorongo and future corpora. These are hypothesis/falsification tracks, not automatic translation claims.
3. 4D Lattice Lab: formal definitions, invariants, simulations, ablations, stability, scaling and simpler-baseline comparisons.
4. Agent Orchestration Arena: single vs multi-agent, coordinator ablations, independent worktrees, disagreement, communication overhead, verifier independence, latency/cost/accuracy.
5. Mathematics Lab: proof checking, symbolic/numeric agreement, counterexample search, hidden problems and independent proof verification.
6. Algorithm Forge: competing algorithms, hidden tests, complexity/performance baselines, adversarial cases and reproducible retention criteria.
7. Verification Matrix: factuality, citations, hallucination resistance, long-context consistency, multilingual reasoning, safe cybersecurity benchmarks, corrupted-input recovery, prompt-injection resistance and model disagreement.
8. Evidence Vault / Scoreboard: immutable experiment identities, hashes, settings, outputs, grader evidence, remediation history, uncertainty, cost and replication state.

## Required ablations
Where applicable compare:
- model alone vs AUREX;
- AUREX without vs with 4D lattice;
- single-agent vs orchestration;
- orchestration without vs with independent verifier;
- unremediated vs remediated;
- proposed algorithm vs simplest credible baseline.

A complex system earns credit only for measured incremental value.

## Decipherment admission rules
A decipherment hypothesis must separate fit from prediction. It advances only through independent anchors, out-of-sample predictions, competing-hypothesis comparison and falsification attempts. Pattern fit, semantic plausibility or internal consistency alone is NOT a decipherment.

## Benchmark admission rules
Authorized datasets only. Freeze dataset revision, item IDs, model/settings, tools, prompts, retries, randomization and scoring protocol. Keep withheld references unavailable during generation. Independent grading and contamination checks are mandatory before external performance claims.

## Test matrix
Every applicable experiment records:
- correctness / task score;
- calibration and abstention;
- evidence provenance and freshness;
- reproducibility;
- contamination / leakage;
- adversarial robustness;
- cross-model independence;
- regression count;
- latency and cost;
- uncertainty / effect size;
- baseline delta;
- replication status.

## Result states
PASS, FAIL, HOLD, NOT RUN, NOT VERIFIED.

No inferred PASS. Infrastructure failure is not PASS. Unknown is not healthy. A failed test remains historical evidence after remediation.

## Anti-gaming gates
No self-grading; no post-hoc benchmark selection; no hidden baseline weakening; no deleting failed trials; no tuning on withheld answers; no duplicated items counted as independent evidence; no unverifiable boolean declaration treated as attestation; no model-family independence claim without recorded identities.

## Promotion ladder
EXPERIMENTAL -> REPRODUCED -> INDEPENDENTLY VERIFIED -> ADMITTED.

Only independently verified evidence can support a public superiority or decipherment claim. AUREX output alone cannot promote itself.
